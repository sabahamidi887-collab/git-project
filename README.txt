پورتفولیوی ساده صبا حمیدی

1. این پوشه را در VS Code باز کن.
2. فایل index.html را با مرورگر اجرا کن.
3. اگر عکس خودت را می‌خواهی اضافه کنی، یک پوشه به نام pictures بساز و عکس را با نام profile.jpg داخل آن بگذار.
4. متن‌ها را در index.html و رنگ‌ها و ظاهر را در style.css تغییر بده.

این نسخه با مفاهیم مقدماتی HTML و CSS ساخته شده و فرم تماس آن فعلاً نمایشی است.
